# EHXLang

EHXLang is a programming language created by Ethio Hacker X.

## Version

EHXLang 0.1.0

## Vision

EHXLang is designed to eventually support:

- General programming
- Automation
- Cybersecurity education
- Tool development
- CTF/lab development
- System scripting

## Example

```ehx
# My first EHXLang program

set name = "EHX"
set year = 2026

set x = 10
set y = 20

say name
say year
say x + y
