# EHXLang for VS Code

Syntax highlighting and basic language support for EHXLang.

## Features

- `.ehx` file recognition
- EHXLang syntax highlighting
- Comments
- Strings
- Numbers
- Variables
- Operators
- `set`
- `say`
- Auto-closing brackets
- Auto-closing strings

## EHXLang

EHXLang is a programming language created by Ethio Hacker X.

Current language version:

`0.1.0`
